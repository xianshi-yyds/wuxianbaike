Visual Knowledge Atlas local demo

How to open the merged app:
1. Run `npm install` once if node_modules is missing.
2. Run `npm run dev`.
3. Open http://localhost:3000

Static preview:
- You can still double-click public/open.html to preview the old landing page.
- The account-based 无限探索 module requires the local Next server.

Notes:
- /open.html keeps the original AI 无限百科 landing page.
- /infinite-explore is the merged module with account login, server-side history, and generated image storage.
- If the browser blocks local audio autoplay, click the voice button manually.
